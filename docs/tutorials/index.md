# Tutorials

These lessons build small, complete designs. Follow the steps in order in a
writable directory; generated files can be opened in a browser or SVG viewer.

Start with [your first pattern](first-pattern.md) to install the Python package,
generate a hobnail grid, and inspect its sampled lines. Continue with
[a patterned watch dial](watch-dial.md) to combine a full-dial texture with an
offset motif. [A rose-engine pattern](rose-engine.md) introduces a rosette,
cutting bit, and multi-pass run.

Each lesson uses one route through the API. For task-specific alternatives,
see [the how-to guides](../how-to/index.md). Exact defaults and constraints are
in [reference](../reference/index.md).
